### PROJECT INFORMATION
SupportBoard is a containerized Telegram bot built with Node.js and TypeScript for managing support tickets directly inside Telegram groups. It enables teams to create, organize, and track support topics (tickets) with role-based access control for admins and clients.

The project includes persistent storage, multi-language support (English, Ukrainian, Russian), configurable limits for topic management, and system message filtering to keep conversations clean. It is designed for production use with Docker-based deployment and a CI/CD pipeline that publishes versioned images to GitHub Container Registry (GHCR).
