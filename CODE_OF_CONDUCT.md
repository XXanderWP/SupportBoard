# Contributor Covenant Code of Conduct

Our project follows the Contributor Covenant v2.1. We expect all contributors to be respectful and considerate.

Unacceptable behavior includes harassment, discrimination, and other actions that exclude contributors.

If you experience or witness unacceptable behavior, please contact the maintainers at maintainers@supportboard.com.

We will review reports and take appropriate action, which may include removing contributors from the project.

For the full text, see: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
