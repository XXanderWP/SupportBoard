# Contributing to SupportBoard

Thanks for considering contributing — we appreciate it! This guide explains the basics to make contributing smooth and friendly.

## How to contribute
- Open an issue to discuss large changes before implementation.
- For small fixes, open a pull request with a clear description.

## Branching & commits
- Use feature branches: `feature/...`, `fix/...`, `chore/...`.
- Prefer Conventional Commits for messages (e.g., `fix(auth): correct token handling`).

## Pull request process
- Fork the repo and create a branch for your change.
- Run tests and linters locally.
- Open a PR and reference related issues.
- Keep PRs focused and small where possible.

## Code style and tests
- Follow the existing TypeScript style and formatting.
- Add or update tests for your change. Run `npm test`.

## Local development
Install dependencies and run tests:

```bash
npm ci
npm test
```

## Need help?
If you're unsure about something, open an issue or join the discussion.
